## استفاده

```php
use Tavaan\Engine\Media\Media;
use Tavaan\Engine\Media\MimeDetector;
use Tavaan\Engine\Media\Uploader;
use Tavaan\Engine\Media\ImageProcessor;
use Tavaan\Engine\Media\MediaServiceProvider;

// Setup
$provider = new MediaServiceProvider([
    'allowed_extensions' => ['jpg', 'png', 'pdf'],
    'max_size' => 10485760,
    'image_driver' => 'auto',
]);
$provider->register();
$uploader = $provider->getUploader();
$processor = $provider->getProcessor();
$detector = $provider->getDetector();

// آپلود
$media = $uploader->upload($tmpPath, 'photo.jpg', 'storage/app/uploads');
$media->path;
$media->mimeType;
$media->size;
$media->isImage();

// تشخیص MIME
$mime = $detector->detect('/path/to/file.jpg');
$detector->extensionMatchesMime('jpg', $mime);

// پردازش تصویر
$processor->resize('source.jpg', 'thumb.jpg', 150, 150);
$processor->thumbnail('source.jpg', 'thumb.jpg', 150);
$info = $processor->dimensions('source.jpg');
// ['width' => 800, 'height' => 600, 'type' => 'jpeg']

// مستقیم
$u = new Uploader(maxSize: 100 * 1024 * 1024, allowedExtensions: ['jpg', 'png']);
$d = new MimeDetector();
$p = new ImageProcessor('gd');
```

## امنیت 🔒

- تشخیص MIME از **magic bytes** (نه از content-type کاربر)
- تطبیق extension با MIME (جلوگیری از `.php` با `image/jpeg`)
- rename با random hex (حذف نام اصلی)
- ذخیره خارج از DocumentRoot (یا با execution off)
